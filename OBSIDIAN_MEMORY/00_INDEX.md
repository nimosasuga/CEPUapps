# Indeks Memori CEPUapps

Vault ini dipakai Obsidian dan opencode untuk konteks project.

## Folder
- `01_RULES/` aturan wajib project.
- `02_ARCHITECTURE/` peta file, alur data, modul penting.
- `03_DECISIONS/` keputusan teknis dan alasan.
- `04_SESSIONS/` ringkasan sesi kerja opencode.
- `05_BUGS/` bug, akar masalah, fix, regresi.
- `06_DEPLOYMENTS/` log versi, commit, deploy, rollback.
- `07_TEMPLATES/` template catatan.
